    Die vier Varianten
    
    
    Alle vier liegen im Repository unter prototypes/begleitfenster (Branch claude/jolly-volta-3ylu54), das Zip ist im Chat. Die Seite hier ersetzt keinen der Prototypen, sie zeigt nur das gemeinsame Panel.
    
    
    
      
    
        
    D1Schwebendes Fenster
    
        
    Ein kleines Fenster, das immer im Vordergrund über der getesteten Anwendung liegt. Chrome und Edge ab Version 116, keine Installation.
    
        
    Kann
    • immer im Vordergrund
    • Screenshot per Fensterfreigabe
    Kann nicht
    • zum Feld springen
    
        
    1. Ordner mit python3 -m http.server 8000 bereitstellen
    2. localhost:8000/d1-pip/ öffnen, «Begleitfenster öffnen»
    3. Test-Anwendung in einem anderen Fenster öffnen
    
        
     
    
        
    Geprüft: Fenster öffnet sich und zeigt das Panel. Offen: Verhalten auf deinem Bildschirm, Edge.
    
      
    
      
    
        
    D2Browser-Erweiterung
    
        
    Panel in der Seitenleiste von Chrome oder Edge, daneben die getestete Web-Anwendung.
    
        
    Kann
    • Feld markieren und anspringen
    • Screenshot der Seite ohne Freigabe
    Kann nicht
    • Desktop-Software
    • ohne Installation der Erweiterung
    
        
    1. edge://extensions oder chrome://extensions öffnen
    2. Entwicklermodus, «Entpackte Erweiterung laden», Ordner d2-extension
    3. Test-Anwendung öffnen, Symbol anklicken
    
        
    Geprüft in Chromium: markieren, fokussieren, Springen beim Schrittwechsel, Screenshot. Offen: Seitenleiste selbst, Edge.
    
      
    
      
    
        
    D3Gesteuerter Browser
    
        
    gherkit startet den Browser mit der Anwendung und blendet das Panel in die Seite ein. Das Panel lässt sich verschieben und einklappen.
    
        
    Kann
    • zum Feld springen
    • Nachweis automatisch
    • Ergebnisse in Datei
    Kann nicht
    • Desktop-Software
    • braucht Node.js beim Tester
    
        
    cd prototypes/begleitfenster/d3-launcher
npm install
node launch.mjs https://meine.app
    
        
    Geprüft in Chromium: Panel in der Seite, Springen, Nachweis, Zustand nach Neuladen. Offen: Edge (unter Windows Standard), eigene Anwendung.
    
      
    
      
    
        
    D4Desktop-Fenster
    
        
    Eigenes kleines Fenster, rahmenlos und immer im Vordergrund, für jede Anwendung, auch Desktop-Software.
    
        
    Kann
    • jede Anwendung begleiten
    • Screenshot des Bildschirms
    Kann nicht
    • zum Feld springen
    • am grössten im Aufwand
    
        
    cd prototypes/begleitfenster/d4-desktop
npm install
npm start
    
        
    Nicht gelaufen: Electron ließ sich in der Sandbox nicht installieren. Geprüft ist nur die Oberfläche in Chromium.
