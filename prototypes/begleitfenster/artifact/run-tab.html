Prototyp: der echte Run-Tab mit Begleitfenster

Diese Seite läuft mit dem echten Code des Editors (run.js und style.css) und den manuellen Szenarien aus examples/bibliothek. Nur der Server ist in der Seite nachgebaut, der Lauf bleibt in diesem Browser.

  1. Unten einen Lauf starten (Name eingeben).
  2. «Begleitfenster» anklicken. Das kleine Fenster zeigt nur den aktuellen Schritt.
  3. Mit den Knöpfen oder mit G, S, I, ← durch den Test gehen. Der Run-Tab folgt mit.
  4. «Screenshot» legt ein simuliertes Bild als Nachweis an. Ergebnisse siehst du im Tab «Ergebnisse».

Simuliert: Das Fenster ist ein verschiebbarer Rahmen in der Seite. Echt: ein eigenes Fenster, das über allen anderen liegt. Die Anzeige und die Bedienung sind in beiden Fällen dieselben.
