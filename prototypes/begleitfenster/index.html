Begleitfenster für manuelle Tests: Prototypen

Vier Varianten, dasselbe Panel, dieselben Beispiel-Szenarien. Anleitung zum Ausprobieren: README.md.

VarianteStartKann
D1 Schwebendes Fensterd1-pip/index.html (Seite über http://localhost öffnen)immer im Vordergrund, keine Installation; kein Springen zum Feld
D2 Browser-Erweiterungd2-extension/ als entpackte Erweiterung ladenSeitenleiste, Feld markieren und anspringen, Screenshot der Seite
D3 Gesteuerter Browsernode d3-launcher/launch.mjsPanel in der Seite, Feld anspringen, Nachweis automatisch, Ergebnisse in Datei
D4 Desktop-Fensterd4-desktop/: npm install, npm startimmer im Vordergrund für jede Anwendung, Screenshot des Bildschirms

Die Test-Anwendung ist ein einfaches Formular, an dem die Beispiel-Szenarien durchgespielt werden.
