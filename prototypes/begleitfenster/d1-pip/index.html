D1 – Schwebendes Begleitfenster

Das Begleitfenster liegt immer im Vordergrund über der getesteten Anwendung (Document Picture-in-Picture, Chrome und Edge ab Version 116). Diese Seite muss dafür offen bleiben, sie kann aber im Hintergrund liegen.

  2. Test-Anwendung öffnen (oder eine beliebige andere Anwendung in einem anderen Fenster)
  3. Test durchführen: Tasten G Gut, S Schlecht, I Ignorieren, ← zurück. «Nachweis» fragt einmal, welches Fenster freigegeben wird, danach genügt ein Klick.

Ohne Picture-in-Picture (anderer Browser) öffnet sich ein kleines normales Fenster, das nicht automatisch im Vordergrund bleibt. Zum Feld springen kann D1 nicht (ein Browser darf nicht in eine fremde Seite eingreifen): dafür D2 oder D3.
