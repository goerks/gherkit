Gherkin schreiben, prüfen und ausführen lassen

gherkit ist ein einzelnes Programm für den ganzen Gherkin-Workflow: formatieren, prüfen, im Browser bearbeiten und Testergebnisse als Report darstellen. Ohne Installation von Laufzeiten, für alle Runner.

Im Aufbau. Die Browser-Demo entsteht Schritt für Schritt. Schon jetzt läuft die echte CLI als Terminal auf dieser Seite; der Editor im Browser folgt als Nächstes.

Ausprobieren im Browser

Das ist die echte gherkit-CLI, im Browser ausgeführt. Sie arbeitet auf einem virtuellen Ordner mit Beispieldateien. Ihre Eingaben bleiben in Ihrem Browser und werden nicht übertragen.

Lädt beim Start etwa 3 MB.

In einer Minute ausprobieren

Entpacken, im Ordner eine Eingabeaufforderung oder ein Terminal öffnen:

gherkit edit examples
gherkit fmt --check examples
gherkit lint --strict examples

Der Editor öffnet sich im Browser unter 127.0.0.1:4848. Alles bleibt auf Ihrem Rechner.

Ergebnisse Ihrer Tests zu einem Report machen:

gherkit run --adapter go
gherkit report results.json -o report.html

gherkit startet den Runner Ihres Projekts (Go, Java oder ein eigenes Kommando) und liest dessen Cucumber-JSON.

Was gherkit kann

Formatieren und prüfen

Mit dem offiziellen Gherkin-Parser, in allen 80 Sprachen. Das Format ist gegen den offiziellen Testkorpus abgesichert.

Editor im Browser

Code mit Vorschlägen, ein Formular für Fachleute, eine Vorschau und die daraus entstehenden Testfälle.

Für jeden Runner

Go (godog), Java (Cucumber-JVM) oder jedes Kommando, das Cucumber-JSON schreibt.

Reports

HTML, Markdown oder JSON, mit eigenen Vorlagen und in Deutsch oder Englisch.
